# OpenSwitcher (macOS)

Mac-порт [OpenSwitcher](https://github.com/nick8cyber/open-switcher) —
Windows-аналога Punto Switcher / Caramba Switcher с открытым исходным кодом.
Вся логика и дизайн перенесены 1 в 1; платформенная часть заменена на нативную
для macOS.

Автоматически исправляет слова, набранные не в той раскладке (Ru ⇄ En), и умеет
главное — **автоисправление по Enter, как в Punto, с возможностью его отключить**.

## Возможности

| Функция | Описание | По умолчанию |
|---|---|---|
| Автоисправление при вводе | Слово проверяется в конце ввода (пробел, запятая, точка…). Разделитель проглатывается и досылается после исправления; при зажатых Ctrl/Alt/Cmd не вмешивается | **вкл** |
| Исправлять слово перед Enter | Работает только на голый Enter: Shift/Ctrl/Alt+Enter (перенос строки, команды) не трогаются | **вкл** |
| Исправить последнее слово | `Ctrl+Space` — каретка сразу после слова: исправляет точно; каретка уже ушла — сам выделяет слово слева (Option+Shift+←) и конвертирует | `Ctrl+Space` |
| Исправить выделенный текст | По умолчанию не назначено: выделение конвертирует тап Option (переключит слово/выделение — select-left fallback). Комбинацию «копирует выделение → конвертирует → вставляет обратно → меняет раскладку (как в Caramba)» можно назначить в настройках («Горячие клавиши») | Не задано |
| Клавиша РУС / ENG раскладки | Одиночный тап клавиши (левый Shift → РУС, правый Shift → ENG; можно Caps Lock и т.п. — нативное действие глотается) или сочетание с модификаторами | левый/правый Shift |
| Отменить последнюю автозамену | Основная отмена — `Backspace` сразу после замены: возвращает слово и раскладку до автозамены. Откат безопасен: отменяется, если после замены печатали, кликнули мышью, сменили окно или прошло >15 с. Отдельный хоткей отката по умолчанию не задан (прошлый `F15` не существует на современных Mac-клавиатурах) — можно назначить свою комбинацию в настройках | `Backspace` после замены |
| Запоминание отмен | Слово, автозамену которого ты отменил, больше не конвертируется автоматически | вкл |
| Пауза автоперевода | Глобальный тумблер; ручные хоткеи продолжают работать | есть в меню |
| Двойной Shift | Смена раскладки двойным нажатием Shift (недоступно, пока тап-переключение висит на Shift'ах — по умолчанию так) | вкл |
| Option-тап — перевернуть слово | Как в Caramba: короткий голый тап Option принудительно переворачивает живой буфер или последнее слово (≤10 с, известен разделитель) — «пинг-понг» без rejected-блокировок и без самообучения; свежего слова нет — выделяет слово слева (Option+Shift+←) и конвертирует | вкл |
| Вставить без форматирования | Как в Caramba: заменяет буфер обмена чистым текстом и вставляет. Переназначается в настройках («Горячие клавиши»); Backspace в поле — «Не задано» = функция выключена | `Cmd+Shift+V` |
| Оба Shift — вкл/выкл автопереключение | Зажать левый + правый Shift одновременно (чистая пара — ни одной клавиши между) — пауза/возобновление автоисправления, как в Caramba | выкл |
| Всплывающая подсказка | Плашка `ghbdtn → привет` у курсора | вкл |
| Восстановление буфера обмена | После конвертации выделения старый буфер возвращается | вкл |
| Тема | «Системная» следит за светлой/тёмной темой macOS; можно закрепить светлую или тёмную | системная |
| Исключения | Список приложений (через запятую), где выключено только автоисправление | пусто |
| Режим разработчика | Журнал решений в файле log.txt для отладки (F8 — метка проблемы в журнале) | выкл |

## Как принимается решение

Слово — последовательность букв без разделителей. При завершении слова
(пробел / знак / Enter) программа:

1. Рендерит нажатые клавиши во **всех установленных раскладках** через
   `UCKeyTranslate` (поэтому работают любые пары QWERTY/ЙЦУКЕН).
2. Оценивает «естественность» каждого прочтения по частотам букв и биграмм.
3. Если прочтение на другом языке уверенно выигрывает и содержит гласную —
   слово исправляется: Backspace'ы стирают его, текст вводится «юникодом»
   (`CGEventKeyboardSetUnicodeString`), раскладка переключается
   (`TISSelectInputSource`), Enter досылается после исправления.

## Сборка

Нужен Xcode Command Line Tools:

```bash
./build.sh            # хост-архитектура
./build.sh arm64      # Apple Silicon (M1…)
./build.sh x86_64     # Intel
./build.sh universal  # универсальный бинарник (обе архитектуры)
```

Соберёт `build/OpenSwitcher.app` и прогонит self-test детектора
(selftest пропускается, если целевая архитектура не исполняема на хосте).
Готовые сборки — в [Releases](../../releases) репозитория:
`OpenSwitcher-macOS-AppleSilicon-M1-M6.app.zip` (Mac на чипах M1…M-серии) и
`OpenSwitcher-macOS-Intel-old-Macs.app.zip` (старые Mac на Intel). Какой у тебя
процессор: меню  → «Об этом Mac» — строка «Чип» (Apple Silicon) или
«Процессор» (Intel).

Полезные режимы:

```bash
OpenSwitcher.app/Contents/MacOS/OpenSwitcher --settings   # открыть настройки при старте
OpenSwitcher.app/Contents/MacOS/OpenSwitcher --simtest ghbdtn  # прогон через реальные раскладки
OpenSwitcher.app/Contents/MacOS/OpenSwitcher --selftest    # автотесты детектора
```

## Первый запуск — разрешения macOS

Для работы нужны **оба** разрешения (Системные настройки → Конфиденциальность
и безопасность):

1. **«Мониторинг ввода»** — чтение клавиш. Без него программа не видит нажатий;
   при первом запуске появится алерт с кнопкой открытия нужной панели.
2. **«Универсальный доступ»** (Accessibility) — внесение исправлений
   (инжекция текста). Без него приложение **читает клавиши, но не исправляет
   текст**. Как только заработает чтение, OpenSwitcher сам попросит это
   разрешение (один раз за запуск).

Приложение подхватывает оба разрешения само (watchdog пересоздаёт тап в
течение 10 с) — перезапуск не нужен. Если «говорят, что не работает»: правый
клик по иконке → **«Проверить разрешения»** — покажет статус обоих пунктов
(✓/✗) и кнопки открытия обеих панелей Системных настроек.

Поддерживаются позиционные раскладки (ЙЦУКЕН / QWERTY). **Фонетические
русские раскладки не поддерживаются** — детект считает прочтения по позиции
клавиш.

## Запуск

`OpenSwitcher.app` — иконка в строке меню. Клик — настройки, правый клик/клик —
меню (Настройки / Пауза / Выход). Автозапуск включается в настройках
(LaunchAgent).

Настройки хранятся в `~/Library/Application Support/OpenSwitcher/settings.ini`,
словарь обучения — `learned.txt` / `accepted.txt`, журнал решений — `log.txt`.

## Отличия порта от Windows-версии

- Раскладка переключается системно (`TISSelectInputSource`) — macOS не даёт
  задать раскладку отдельному окну, как `WM_INPUTLANGCHANGEREQUEST`.
- Подсказка показывается у курсора мыши: каретку чужого окна macOS не отдаёт.
- У `Break` нет клавиши-аналога по умолчанию: `F15` (Pause/Break) отсутствует
  на современных Mac-клавиатурах, поэтому хоткеи отката не назначены — отмена
  делается `Backspace` сразу после замены, свою комбинацию можно задать в
  настройках; «выделить слово слева» — `Option+Shift+←` вместо `Ctrl+Shift+←`.
- Копирование/вставка выделения — через `Cmd+C`/`Cmd+V` и `NSPasteboard`
  (аналог WM_COPY/Ctrl+C/Ctrl+V).
- Собственная инжекция помечается в поле `kCGEventSourceUserData` события и
  глотается в тапе (аналог бита LLMHF_INJECTED).

## Синхронизация со спекой v3 (docs/SPEC.md оригинала)

Порт синхронизирован со спецификацией v3 (30 аудиторских находок оригинала):

- **Одиночные буквы по «словности»**: 'f'+пробел → «а», 'f'+Enter → «а» с досылом;
  «неприкасаемые» (а/и/в/к/о/с/у/я, a/i) не переворачиваются; паттерн [буква][знак]
  («z,» → «я,»); раскладка при одиночной букве не меняется.
- **Хвост-двойник**: «ghbdtn,» → «привет,» (знак остаётся знаком, не «приветб»).
- **PossibleWord** из корпуса OpenSubtitles 55k слов: конвертятся формы вне словаря
  («нажимал»→'yf;bvfk', «запусти»→'pfgectnb').
- **Кулдаун 5 с** после backspace-cancel/Break-отката — авто-конвертации молчат.
- **Эхо-фильтр пробела**: окно 600 мс, одноразовый.
- **Suppress-окно: пробел делит буфер** (слова больше не слипаются).
- **Force-flip (Break)**: точный путь ≤10 с с известным разделителем и тем же
  окном; разделитель сохраняется; одиночная буква — без смены раскладки.
- **F8** — метка проблемы в журнал; трассировка решений по пробелу.
- **verify-switch**: проверка применения раскладки через 400 мс с повтором.
- **Инжекция адресуется pid** переднего приложения (CGEventPostToPid) — смена
  окна в момент доставки не уносит текст в другое окно.
- Минус — буква (держит «какой-то» целиком), '\' — разделитель;
  `LockAutoAfterManualSwitch=1` по умолчанию (владелец отменил спеку §18:
  классика Punto/Caramba — ручной тап глушит автодетект до смены окна или
  паузы 3 с; миграция defaultsV 10 включает лок и старым ini).

## Осознанные упрощения против Windows-версии

- Меню иконки — системное (без ручной темизации DarkMenuRenderer); поля хоткеев
  показывают текст «Ctrl + Space» вместо чипов-клавиш; окно настроек закрывается
  системным крестиком (Esc не обрабатывается) — стилевые упрощения macOS-версии.
- Отмена автозамены хранит только приложение (pid), а не окно и поле ввода:
  в другом окне того же приложения в течение 15 с откат может примениться
  в не то окно (macOS не отдаёт чужие окна/фокус). Смена приложения и key-окна
  сбрасывает откат.
- Метка F8 присутствует (снимок состояния в журнал); в отличие от Windows
  в снимке нет hwnd/hkl — на macOS им нет прямого аналога.
- Всплывающая подсказка всегда одна: новая заменяет предыдущую (в оригинале
  плашки наслаивались).
- Ключ настроек `InputMode` (SendInput vs сообщения окна) не существует —
  на macOS один канал инжекции (CGEvent).
- «Двойной Shift» отключён, пока тап-переключение висит на Shift'ах
  (спека §10/§18: иначе второй тап «съедается»); тумблер в настройках
  задизейблен с пояснением.
- Унаследовано от оригинала (не дивергенции порта): Backspace внутри 0,6-с
  suppress-окна проходит в текст мимо отмены замены; Break после допечатывания
  разворачивает хвост в старую раскладку («реплей клавиш», а не восстановление
  видимого текста); инжекция, прилетевшая в момент смены окна, может уйти в
  новое окно; слово длиннее 40 букв заменяется со сдвигом; анти-эхо глотает
  легитимные пробелы быстрее 250 мс после автозамены.
- Кнопка «Сбросить» в настройках мгновенно применяет тему по умолчанию
  (до «Сохранить») — в Windows-версии перекраски не было.
- Точка отката ставится безусловно (спека §5.1 требует — только при реально
  доставленной инжекции): у CGEventPostToPid нет отчёта о доставке; зато
  адресация в pid исключает главную причину потерянных инжекций.
- Свои инжекции распознаются полем события kCGEventSourceUserData, а не
  приватным CGEventSource (вариант из карты порта §16) — поведение то же.
- Break при нечего-отменять: после «живого буфера» и точного пути — честный
  отказ с подсказкой (паритет коду v3); выделение слова слева осталось только
  у Ctrl+Space (так задумано §9).
