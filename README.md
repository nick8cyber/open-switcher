# OpenSwitcher

Windows-аналог Punto Switcher / Caramba Switcher с открытым исходным кодом.
Автоматически исправляет слова, набранные не в той раскладке (Ru ⇄ En),
и умеет главное — **автоисправление по Enter, как в Punto, с возможностью его отключить**
(в Caramba эту возможность убрали).

## Возможности

| Функция | Описание | По умолчанию |
|---|---|---|
| Автоисправление при вводе | Слово проверяется в конце ввода (пробел, запятая, точка…). Разделитель проглатывается и досылается после исправления; при зажатых Ctrl/Alt/Win не вмешивается | **выкл** (включается осознанно) |
| Исправлять слово перед Enter | Работает только на голый Enter: Shift/Ctrl+Enter (перенос строки, команды) не трогаются. Разделитель/Enter досылаются после исправления | **выкл** |
| Исправить последнее слово | `Ctrl+Space` — конвертирует последнее набранное слово (в т.ч. после пробела/Enter, пока не прошло 3 сек) | `Ctrl+Space` |
| Исправить выделенный текст | `Ctrl+Shift+Space` — копирует выделение, конвертирует, вставляет обратно и переключает раскладку | `Ctrl+Shift+Space` |
| Клавиша РУС / ENG раскладки | Одиночный тап клавиши (левый Shift → РУС, правый Shift → ENG по умолчанию; можно Caps Lock, F9 и т.п. — нативное действие глотается) или сочетание с Ctrl/Alt/Win. Тап с зажатым Ctrl/Alt/Win не срабатывает — не конфликтует с Alt+Shift | левый/правый Shift |
| Отменить последнюю автозамену | `Break` — возвращает слово и раскладку, которые были до автозамены. Откат безопасен: отменяется, если после замены печатали, кликнули мышью, сменили окно или прошло >15 сек | `Break` |
| Запоминание отмен | Слово, автозамену которого ты отменил, больше никогда не конвертируется автоматически (в любом приложении; `Ctrl+Space` исправит вручную). Хранится в `%APPDATA%\OpenSwitcher\learned.txt` | вкл |
| Пауза автоперевода | Глобальный тумблер всего авто; ручные хоткеи при паузе продолжают работать | не назначена (есть в меню трея) |
| Двойной Shift | Смена раскладки двойным нажатием Shift | выкл |
| Всплывающая подсказка | У каретки появляется плашка `ghbdtn → привет` | вкл |
| Восстановление буфера обмена | После конвертации выделения старый буфер возвращается | вкл |
| Тема | «Системная» следит за светлой/тёмной темой Windows и перекрашивается на лету; можно закрепить светлую или тёмную | системная |
| Исключения | Список процессов (через запятую), где выключено только автоисправление; ручные хоткеи продолжают работать | пусто |

Все горячие клавиши переназначаются в настройках (для букв/цифр требуется Ctrl или Alt).

## Как принимается решение

Слово — последовательность букв без разделителей. При завершении слова
(пробел / знак / Enter) программа:

1. Рендерит нажатые клавиши во **всех установленных раскладках** через `ToUnicodeEx`
   (поэтому работают любые пары QWERTY/ЙЦУКЕН, включая Dvorak).
2. Оценивает «естественность» каждого прочтения для своего языка по частотам
   букв и биграмм (тем же методом работали ранние Punto / Keyboard Ninja).
3. Если прочтение на другом языке уверенно выигрывает (порог настраивается,
   «чувствительность») и содержит гласную — слово исправляется: backspace'ы
   стирают его, текст вводится «юникодом» (`KEYEVENTF_UNICODE`), раскладка
   переключается (`WM_INPUTLANGCHANGEREQUEST`), при срабатывании по Enter —
   Enter досылается после исправления.

Мелкие слова короче минимальной длины (по умолчанию 3) не трогаются,
чтобы не портить `bd`, `qwe` и т.п. Двусмысленные слова (когда скор близок)
остаются как есть.

## Сборка

Нужен только Windows с .NET Framework 4.x (есть на любой Win10/11), ничего
устанавливать не надо:

```cmd
build.cmd
```

Соберёт `OpenSwitcher.exe` и прогонит self-test детектора
(`OpenSwitcher.exe --selftest`).

Полезные режимы:

```cmd
OpenSwitcher.exe --settings          % открыть настройки при старте
OpenSwitcher.exe --simtest ghbdtn    % прогон строки через реальные раскладки
OpenSwitcher.exe --selftest file.txt % автотесты детектора
```

## Запуск

`OpenSwitcher.exe` — иконка в трее. Левый клик — настройки, правый — меню
(Настройки / Пауза / Выход). Автозапуск включается в настройках.

Настройки хранятся в `%APPDATA%\OpenSwitcher\settings.ini`.

## Известные ограничения

- Пара языков: русский ⇄ английский (стандартная ЙЦУКЕН/CDPAH qwerty).
- В окна с правами администратора ввод не попадёт, если сам OpenSwitcher
  запущен без прав администратора (запустите его от админа при необходимости).
- Games/программы с DirectInput могут игнорировать `SendInput` — добавляйте
  их в исключения.
- Конвертация выделенного текста использует буфер обмена (как в Punto).

## Структура

```
src/
  Program.cs          точка входа, single-instance, автозапуск
  SelfTest.cs         автотесты детектора + --simtest
  Core/
    Native.cs         P/Invoke (хуки, SendInput, ToUnicodeEx, DWM)
    Settings.cs       модель настроек + хранение в %APPDATA%
    LanguageTables.cs частоты букв/биграмм, скоринг, решение о конвертации
    CharMaps.cs       карты ЙЦУКЕН<->QWERTY, KeyRec, буфер слова
    LayoutService.cs  рендер vk-буфера в любой раскладке, переключение
    TextConverter.cs  backspace/unicode/Ctrl+C/V инжекция
    Engine.cs         хуки клавиатуры/мыши, оркестрация исправлений
  UI/
    UiTheme.cs        палитра/шрифты, карточки
    Controls.cs       тогглы, поля хоткеев, сегменты, кнопки, NumBox
    SettingsForm.cs   окно настроек (безрамочное, тёмное, скролл)
    ConvertPopup.cs   подсказка «было → стало» у каретки
    TrayService.cs    иконка трея и меню
```

## Опенсорс-альтернативы, которые рассматривались

- **Mahou** (iamkarlson/Mahou, C#) — самый близкий опенсорс: конвертация по
  хоткеям (Pause/Scroll), но **нет автоопределения неверной раскладки** —
  а именно это ядро Punto/Caramba. Отсюда решение писать свой движок.
- **Easy Switcher** (freemind001) — Linux.
- **langSwitcher** (reg2005) — macOS.
- Различные AutoHotkey-скрипты — только ручная конвертация, без детектора.

OpenSwitcher берёт у Mahou механику инжекции ввода (проверенную годами),
у Punto — автоисправление по Enter с тумблером, у Caramba — минимализм.
