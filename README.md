# OpenSwitcher

Автоисправление слов, набранных не в той раскладке (Ru ⇄ En) — открытый
аналог Punto Switcher / Caramba Switcher. Два приложения в одном репозитории:

| Папка | Платформа | Стек | Сборка |
|---|---|---|---|
| [`win/`](win/) | Windows 10/11 | C# (.NET Framework 4.x, WinForms) | `cd win && build.cmd` |
| [`macos/`](macos/) | macOS 13+ (Apple Silicon и Intel) | Swift 5.9, AppKit + CGEventTap + TIS | `cd macos && ./build.sh [arm64\|x86_64\|universal]` |

Логика детектора общая и зафиксирована в
[`docs/SPEC.md`](docs/SPEC.md) (v3): частоты/биграммы, ворота конвертации,
одиночные буквы по «словности», хвост-двойник, самообучение, откат.
Mac-порт синхронизирован со спекой и проходит общий selftest детектора.

## Скачать

Готовые сборки — в [Releases](../../releases) по тегам:

- `OpenSwitcher-win.zip` — Windows (anycpu, .NET Framework 4.x предустановлен);
- `OpenSwitcher-macOS-AppleSilicon-M1-M6.app.zip` — Mac на чипах M1…M-серии;
- `OpenSwitcher-macOS-Intel-old-Macs.app.zip` — старые Mac на Intel.

Не знаешь, какой у тебя процессор: меню  → «Об этом Mac» — строка
«Чип» (Apple Silicon) или «Процессор» (Intel).

## Первый запуск

- **Windows**: `OpenSwitcher.exe` — иконка в трее. Настройки — левый клик.
- **macOS**: разрешение «Мониторинг ввода» (и при необходимости
  «Универсальный доступ») — приложение подхватит его само в течение 10 с.
  Подробнее в [`macos/README.md`](macos/README.md).

### Подпись и нотаризация (macOS)

Сборки подписываются сертификатом **Developer ID Application** и отправляются
в Apple на нотаризацию (Gatekeeper). Локально:

```bash
cd macos
./build.sh arm64
codesign --force --deep --options runtime --timestamp \
  --sign "Developer ID Application: <Имя> (TEAMID)" build/OpenSwitcher.app
cd build && ditto -c -k --keepParent OpenSwitcher.app OpenSwitcher.app.zip && cd ..
APPLE_ID=... APPLE_APP_SPECIFIC_PASSWORD=... TEAM_ID=... ./notarize.sh build/OpenSwitcher.app
```

Автоматически — в CI по тегу (секреты `SIGN_IDENTITY`, `DEVELOPER_ID_P12`,
`P12_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `TEAM_ID`).
Без нотаризации Gatekeeper попросит ПКМ → «Открыть» при первом запуске.

## Возможности

- **Автоисправление по концу слова** — «ghbdtn,» + пробел → «привет,».
  Цель конвертации обязана быть словарным (или морфологически валидным)
  словом — правильный текст никогда не портится.
- **Одиночные буквы-предлоги** — «f» + пробел → «а» (по словности: «f» —
  не английское слово, «а» — русское; предлоги а/и/в/к/о/с/у/я и "a"/"i"
  неприкосновенны).
- **Слова с б/ю/ж/э/х/ъ/ё** — не рвутся при наборе в чужой раскладке;
  «ghbdtn,» хвост трактуется знаком («етб» — невозможность, как у Caramba).
- **Break** — откат последней замены (15 с, то же окно/поле ввода);
  Break при нечего-отменять — принудительный переворот последнего слова
  (повторный Break возвращает как было).
- **Ctrl+Space** — точное исправление последнего слова (каретка после
  слова, или слово слева от каретки).
- **Shift+Break** — перевод выделенного текста (буфер обмена
  восстанавливается; смешанное выделение — отказ).
- **Тапы Shift** — левый → русский, правый → английский; буквы, набранные
  в просвете применения раскладки, доставляются уже в новой.
- **Самообучение**: заменённое слово, не отменённое за 15 с, запоминается
  и конвертируется всегда; отменённое — никогда больше (файлы
  `accepted.txt` / `learned.txt`, ≤1000 записей).
- Исключения по процессам, пауза, плашка «было → стало» у каретки,
  тема (системная/светлая/тёмная), ручные хоткеи — всё в настройках.

## Отладка (режим разработчика)

- Настройки → «Режим разработчика» — включает журнал решений в файл
  (`%APPDATA%\OpenSwitcher\log.txt`, ротация 2 МБ). По умолчанию выключен:
  без него не записывается ни одно нажатие.
- **F8** — метка в журнале: снимок состояния (процесс, раскладка, буфер,
  откат, последняя конвертация) на момент глюка.
- `OpenSwitcher.exe --selftest файл` — автотесты детектора (18 кейсов);
  `--simtest слово` — прогон строки через реальные раскладки.

## Сборка (Windows)

```cmd
cd win
build.cmd
```

Соберёт `win/OpenSwitcher.exe` (в корень репозитория ставить не нужно) и
прогонит selftest детектора. Нужен только .NET Framework 4.x — ничего
устанавливать не надо. Подпись exe — `win/tools/sign.ps1` (локальный
сертификат).

## Файлы и настройки

- `settings.ini`, `log.txt`, `accepted.txt`, `learned.txt` —
  `%APPDATA%\OpenSwitcher\`.
- Лок после ручного выбора языка по умолчанию выключен; исключения —
  точные имена процессов («notepad.exe»), через запятую.
