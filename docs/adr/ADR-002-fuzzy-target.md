# ADR-002: Умный режим детектора — цель с опечаткой 1–2 буквы

Статус: принято 01.11.2026 (решение владельца). Реализация: 469df98 (mac),
801c0e4 (win), e6b5035 (дистанция 2, вин+мак). Спека: §5 ворота, шаг 11а.

## Контекст

Ворота авто-конвертации требовали, чтобы «другое» чтение слова было ТОЧНЫМ
словарным словом. Опечатка в неправильной раскладке выпадала целиком:
бой 17:29 — 'cvjmhb' (хотел «смотри», палец на `m` вместо `n`) читалось
как «смоьри» — не слово (невозможное «оь») → отказ; Option-тапы тоже
отказали (слово уже не последнее и старше 10 с). Юзер оставался с мусором.

## Решение

Если (и только если):
- цель-чтение НЕ словарное слово,
- но существует словарное слово на дистанции ≤2 **замен** букв
  ('смоьри' ≈ 'смотри' — dist1; 'првиет' ≈ 'привет' — dist2: смежная
  транспозиция это ровно 2 замены),
- набранное — «глубокий мусор» своего языка: ∉ словарь И биграммно
  невозможно (possible_word = false),

то цель считается валидной → переворот выполняется, буквы сохраняются
как набраны (опечатку правит юзер; автопоправки НЕТ).

Пороги против ложных срабатываний («погрешности»):
- dist1 — длина ≥ 4, маржа скора 1x;
- dist2 — длина ≥ 6 (для коротких две замены — полслова), ПОЛНАЯ маржа 2x;
- только замены — никаких вставок/удалений;
- опечатка СВОЕГО языка ('hellp') биграммно возможна → не трогается
  никогда.

Поиск соседа: перебор замен по алфавиту языка поверх Set-словаря
(WordDict.DictNeighbor / WordDict.dictNeighbor); dist1 ~200 lookup'ов,
dist2 ~15–120k — только на проваленных основных воротах.

## Следствия

- Вин+мак паритет (C#-версия собирается CI на теге).
- Selftest-дискриминаторы: 'hellp' possible (защищено), 'cvjmhb' — нет
  (разрешено), 'првиет' dist2, порог <6 букв, детерминированный 'пкивед'.
- Не срабатывает: ≥3 опечаток, вставки/удаления, слова <4 (dist1) и <6
  (dist2) букв — осознанный предел угадывания; для них — Option-тап
  (живой буфер), выделение+тап (задним числом), Break-форс.
- Угаданный «сосед» используется только как РАЗРЕШЕНИЕ на переворот —
  текст замены всегда буквально то, что набрал юзер.
