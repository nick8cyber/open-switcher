# ADR-003: Слои словаря и расширение членства (топ 200k RU / 150k EN)

Статус: принято 01.11.2026. Реализация: WordDataHuge (mac + win), deny-list v3.

## Контекст

Словарь WordDict.Has служит дискриминатором языка: «это чтение — настоящее
слово». До 01.11 членство держалось на топ-35k RU / топ-20k EN OpenSubtitles
(частотники hermitdave/FrequencyWords) + ручное ядро. Живая речь покрыта,
но книжная/профессиональная/редкая лексика — мимо; умный режим (ADR-002)
усилил зависимость от словаря: сосед по дистанции 1–2 ищется именно в нём.

## Решение

Три слоя, раздельно по назначению:

1. **Ручное ядро** (ruSrc/enSrc в WordDict) — частотное + служебное
   (ctrl/alt/esc…), включая короткие слова <3 букв.
2. **Биграммный корпус** (WordData: топ-35k RU / топ-20k EN, фильтр 3+) —
   ТОЛЬКО источник биграммной модели `possibleWord`. Намеренно НЕ
   расширяется: чем шире биграммы, тем слабее дискриминатор «глубокого
   мусора», на котором держится умный режим (СПЕКА §5 11а).
3. **Членство** (WordDataHuge: топ-200k RU / топ-150k EN, фильтр 4–16
   букв) — только для `WordDict.Has` (ворота цели, cur-in-dict защита,
   поиск соседа умного режима). Плюс ретро-флип/заучивание.

Правила:
- Слой членства — минимум 4 буквы: трёхбуквенный мусор субтитров
  ('vel' и прочая испанщина EN-субтитров) становился «словарным» и ломал
  защиту правильных слов (selftest-бой: 'муд' → 'vel' [CONVERT]).
- **Deny-list решений v3** (`v3Removed`): 'iban' — RU-прочтение с тех же
  клавиш = «шифт» (96f7c2b); никакое расширение словаря решения v3 не
  возвращает.
- Самообучение (accepted/rejected) — поверх всех слоёв, по-прежнему.

## Следствия

- Бинарник 2.0 → 6.6 МБ; память — два Set ≈ 20–30 МБ; наборы строятся
  лениво (первый вызов has), старт приложения не деградирует.
- Fuzzy-соседи ищутся в расширенном словаре: больше настоящих опечаток
  распознаётся; защита от мусорных соседей — cur-гейт + маржа (ADR-002).
- Обновление словаря = перегенерация WordDataHuge из
  hermitdave/FrequencyWords (скрипт-однострочник, источник уже был
  лицензионно принят в 5abcd14).
