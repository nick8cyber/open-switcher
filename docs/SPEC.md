# OpenSwitcher — полная спецификация логики (v3, для порта/воссоздания)

Документ описывает **поведение целиком**, независимо от платформы, и сверен
с исходником `src/` (аудит: 30 находок, все внесены). Разделы «Платформа»
указывают, как это сделано на Windows; при порте реализуется то же поведение
через местные API (см. §16 — карту порта на macOS).

Языковая пара: **русский ⇄ английский** только.

Псевдокод в документе — нормативный. При расхождении текста и псевдокода
приоритет у псевдокода.

---

## 0. Продукт и состав

Фоновый процесс + иконка в трее. Умеет:

1. Автоисправление слова, набранного не в той раскладке, по концу слова
   (пробел/знак/Enter) и по одиночной букве с контекстом.
2. Хоткеи: Break — откат последней замены (или принудительный переворот
   последнего слова, если заменять было нечего); Shift+Break — перевод
   выделенного текста; Ctrl+Space — точное исправление последнего слова;
   тап левого Shift → русский, правого → английский. Всё переназначается.
3. Самообучение: принятые замены запоминаются (конвертируются всегда),
   отменённые — никогда больше не трогаются.
4. Всплывающая плашка «было → стало» у каретки; восстановление буфера
   обмена после конвертации выделения.
5. Настройки в ini; автозапуск; один экземпляр процесса (второй запуск
   открывает настройки); исключения по точному имени процесса.
6. Отладка: F8 — метка в журнал (снимок состояния), полный журнал решений
   с ротацией 2 МБ.

Хранилище: `%APPDATA%\OpenSwitcher\` — `settings.ini`, `log.txt`,
`learned.txt` (rejected), `accepted.txt` (принятые пары).

## 1. Архитектура (платформенная часть — только ввод/вывод)

- Один UI-поток: в нём живёт низкоуровневый хук клавиатуры и мыши, все
  таймеры, журнал. Правило: **хук-колбэк не делает файлового I/O и UI** —
  всё тяжёлое уходит в очередь отложенных задач, исполняемых циклом событий.
- **Порядок стадий keydown-колбэка (норматив):** метка F8 → эхо-фильтр
  пробела → счётчики (работают и внутри suppress-окна) → suppress-
  синхронизация (буквы и пробел буферизуются даже в suppress) → основная
  логика (OnKeyDown).
- Инжекция текста — «backspace × N, затем unicode-ввод целевого текста»
  (не буфер обмена). Два канала: **основной — прямая отправка символов
  (WM_CHAR) в окно фокуса; резервный — системный синтетический ввод**.
  Переключается настройкой InputMode (по умолчанию 1 = сообщения).
- После инжекции — **suppress-окно 600 мс**: обычная обработка клавиш
  приостановлена (см. §6.4), буквы буферизуются, пробел делит буфер.
- **Watchdog 10 с** переустанавливает хуки (ОС молча снимает их при
  таймаутах колбэка); логирует «оживление» и heartbeat раз в 100 с.
- Метка F8: снимок состояния в журнал (см. §15).

macOS-соответствия: активный `CGEventTap` (`kCGEventTapOptionDefault` —
умеет глотать события; listen-only НЕ умеет), права Accessibility и
Input Monitoring; распознавание собственных инжекций — через приватный
`CGEventSource` (аналог флага injected 0x10 на Windows); ОС может молча
отключить тап по таймауту колбэка — watchdog обязан пересоздавать тап и
вызывать `CGEventTapEnable`. Инжекция — `CGEventPostToPid`
(`CGEventPostToPSN` устарел). См. §16.

## 2. Классификация клавиш (критично!)

- **Буквы** = латиница `A..Z` **плюс** клавиши-«двойники» русской
  раскладки: `б=0xBC (',')`, `ю=0xBE ('.')`, `ж=0xBA (';')`, `э=0xDE (''')`,
  `х=0xDB ('[')`, `ъ=0xDD (']')`, `ё=0xC0 ('`')`, минус=`0xBD ('-')`
  (одинаков в обоих языках — введён буквой, чтобы держать «какой-то»
  целиком).
- **Разделители** (конец слова) = пробел, цифры `0x30-0x39` и знаки,
  являющиеся знаками **в обоих** языках: `=` (0xBB), `.` (0xBF), `\` (0xDC).
- ВАЖНО (баг из истории): `ъ` = **0xDD**, а НЕ 0xDC; 0xDC — клавиша `\`.
  Перепутанные коды рвали слова с «ъ» («съел», «объём»).
- **Грубейшая ошибка, запрещённая навсегда:** трактовать б/ю/ж/э/х/ъ/ё как
  разделители — слово рвётся посередине («вообще» = `djj,ot` разваливалось
  на «воо» + б + "ot").

## 3. Поток ввода (машина состояний)

На keydown (не инжектированном, не в suppress-окне):

1. **Буква** → push в буфер слова (`KeyRec: vk, shift, caps`; при
   переполнении до 40 клавиш отбрасываются 10 самых старых); дописать
   «хвост отката» (если ждёт подтверждение замены); буфер ≤ 40 клавиш.
2. **Backspace** → pop буфера; особый случай: один Backspace сразу после
   замены (нажатий между заменой не было, ≤15 с, то же окно, без
   модификаторов, не пауза) = **мгновенная отмена** замены (слово
   возвращается, раскладка возвращается, слово кладётся в rejected,
   ставится кулдаун 5 с). Ctrl+Backspace при живом откате ломает хвост.
3. **Пробел/цифры/знаки-не-двойники** → конец слова: попытка конвертации
   (§5); разделитель проглатывается при успешной замене и досылается
   внутри; иначе проходит как есть. Одиночная буква — §7.
4. **Enter** → конец слова + досыл Enter; откат после Enter запрещён.
5. **Tab/Esc** → сброс буфера.
6. **Клик мышью** → сброс буфера, откат помечается сломанным.
7. **Смена окна/фокуса** → полный сброс: буфер, откат, лок, эхо, хвосты.
   Детект двойной: по событию ОС **и** сверкой hwnd на каждом keydown
   (события ОС теряются).

Порядок обработки в keydown-колбэке хука:
`метка F8 → эхо-фильтр пробела → счётчики (работают и в suppress) →
suppress-синхронизация → основная логика`.

## 4. Точка отката (undo)

Ставится после каждой успешной замены и force-флипа. Поля: целевое слово,
**длина цели** (сколько стирать backspace'ами), фактический разделитель
после слова (символ, как напечатал юзер — не всегда пробел), окно, поле
ввода (фокус), раскладка, тик, хвост (≤16 клавиш, напечатанных после
замены).

Условия отката (Break): ≤15 с; то же окно; тот же фокус ввода; хвост не
сломан (не было Enter/навигации/клика/переполнения). Исполнение: backspace
`(длина цели + длина разделителя + хвост)`, вставить `исходное слово +
разделитель + хвост`, вернуть раскладку; слово → rejected (никогда больше
не конвертируется автоматически), из accepted — удалить.

Backspace-cancel (см. §3.2) = тот же откат плюс rejected.

## 5. Ворота конвертации слова (нормативный порядок)

```
function try_convert(word_keys, sep_vk, sep_shift, manual):
  1. paused                          → skip            # manual тоже
  2. len(word_keys) < 2              → skip            # одиночные буквы — §7
  3. lock_after_manual_switch и autoLocked и не manual → skip
  4. приложение в исключениях → skip                   # точное имя
  5. установленных раскладок < 2 → skip
  6. cur = render(word, currentLayout); язык неизвестен → skip
  7. word.lower() в rejected и не manual → skip
  8. acceptedWord = word.lower() в accepted (только не manual)
  9. best = reading(word) с макс. скором среди ДРУГИХ раскладок
     С ОПРЕДЕЛЁННЫМ языком
 10. хвостовая клавиша-двойник: если best оканчивается «буквой-двойником»
     и прочтение [слово без неё][знак] валиднее (словарь/морфология) —
     цель включает знак: "ghbdtn," → «привет,»
 11. цель: только буквы, ИЛИ [буквы][ровно один знак-двойник-хвост];
     буквенная часть ∈ словарь ИЛИ (len ≥ 3 И possible_word) → иначе skip
     ВНИМАНИЕ: проверять «набранное — возможное слово» ЗАПРЕЩЕНО (§17.2)
 12. scoring: margin 0.22/sens; hard floor −1.35; пол цели EN −0.05,
     RU −0.55; обязательна гласная в цели
 13. acceptedWord пробивает скоринг (цель — только буквы)
 14. dict-over-score: цель ∈ словарь (по буквенной части), набранное ∉ → pass
 15. cur-in-dict protection: набранное ∈ словарь (по буквенной части),
     цель ∉ → отказ
 16. !pass → skip
 исполнение: см. §5.1
```

Кулдаун 5 с (см. §6.2) применяется и к одиночно-буквенному флипу (§7).

### 5.1. Исполнение замены

```
release_modifiers()
backspaces(len(word_keys))           # проглоченный разделитель ещё не в тексте
insert_unicode(target_text)          # цель, включая знак-хвост если был
send_key(разделитель)                # СИМВОЛОМ исходной раскладки (','
                                     # не превращается в «б»); Enter — клавишей
switch_layout(target_layout)         # одиночная буква — БЕЗ смены раскладки
arm_undo_point(...)                  # только если инжекция реально доставлена
schedule_learn(word.lower(), after=15s, unless undone)
popup «было → стало»
```

## 6. Пространственные/временные фильтры

### 6.1. Эхо-фильтр пробела
После досланного пробела реальный пробел в течение **600 мс** при пустом
буфере глотается **один раз** (окно одноразовое: после глотания сброс),
любое другое нажатие закрывает окно. Не глотаются пробелы при непустом
буфере и пробелы вне окна.

### 6.2. Кулдаун
5 с после backspace-cancel или Break-отката — авто-конвертации отключены.

### 6.3. Лок после ручного выбора языка
Опционально (по умолчанию ВЫКЛ — у юзера тапы рефлекторные). Если включён:
после тапа/комбо/ручной правки автодетект молчит **до смены окна или паузы
3 с** (сессионный, не навсегда).

### 6.4. Suppress-окно
600 мс после инжекции: конвертации запрещены; **буквы буферизуются,
пробел делит буфер**; Enter проходит насквозь и буфер НЕ делит (известное
расхождение, см. Engine.cs — ветка suppress).

### 6.5. Gap-компенсация (тап-переключение)
800 мс после ручной смены раскладки буквы, набранные в «просвете» (пока
ОС применяет раскладку), перехватываются: буквы копятся в gap-буфер
(shift/caps фиксируются на момент нажатия), Backspace внутри просвета
уменьшает gap-буфер (или проходит, если буфер пуст), любая другая клавиша
флашит накопленное (инжект юникодом в целевой раскладке, без повторной
смены раскладки) и проходит дальше. Флаш — также при первом keydown, когда
фактическая раскладка уже целевая, либо по дедлайну 800 мс. Захват действует
и в исключённых приложениях (известное поведение).

## 7. Одиночные буквы (предлоги/союзы)

Единственный сигнал — **«словность»**: является ли буква словом своего
языка. Наборы: RU `а и в к о с у я`; EN `a i`.

- Авто-конвертация одиночной буквы **запрещена** (частотный сигнал нулевой,
  «f» и «а» равнозначны) — контекстная эвристика по прошлой конвертации
  ошибается в половине случаев (проверено в бою).
- **Wordness-флип**: одиночная буква переворачивается ТОЛЬКО если (а) она
  не слово своего языка ("f"), и (б) прочтение в другом языке — слово («а»).
  Раскладка при этом НЕ меняется (это правка символа).
- Паттерн **[буква][знак-двойник]**: "z," → «я,» — буква переворачивается
  по словности, хвост остаётся знаком.
- «Неприкасаемые» (а/и/в/к/о/с/у/я, a/i) не переворачиваются никогда.
- Флип на **пробеле** подчиняется общим гейтам (авто-тумблер, лок, кулдаун,
  rejected) и ставит точку отката; флип на **Enter** работает всегда при
  голом Enter и точки отката не ставит.

## 8. Выделенный текст (Shift+Break) — двухфазная конвертация

1. **Фаза хука:** дождаться отпускания модификаторов (до ~0.6 с),
   release_modifiers, определить окно/фокус, бейзлайн буфера обмена
   (текст + sequence number), запустить опрос-таймер 60 мс.
2. **Копирование:** сначала WM_COPY в окно фокуса; для окон класса
   `Chrome_WidgetWin_1` (Chromium) — сразу инжекция Ctrl+C (SendInput).
   Если WM_COPY не дал нового буфера за ~7 тиков (420 мс) — инжекция
   Ctrl+C; лимит опроса 20 тиков (1.2 с).
3. **Конвертация:** текст читается, определяется язык (LettersOnly →
   LangOf; смешанное → отказ «lang unknown»), переворот СТАТИЧЕСКОЙ картой
   `CharMaps.MapText` (не ToUnicodeEx).
4. **Вставка** тем же методом, которым удалось скопировать (Ctrl+C →
   Ctrl+V-инжекция; WM_COPY → WM_PASTE).
5. **Хвост:** переключение раскладки на противоположную, восстановление
   буфера обмена через 800 мс (+ Suppress 300 мс), заучивание пары
   (≥3 букв из выделения).
6. Ретраи: для пути Ctrl+Space («2 слова влево») — Ctrl+Shift+Left ×2 и
   повтор цепочки; для Shift+Break при пустом результате копирования —
   повтор Ctrl+C однократно.

## 9. Force-flip и Ctrl+Space

- **Break при нечего-отменять (force-flip):** переворот последнего слова —
  буфер (≥2 клавиш, живое слово) / последнее слово ≤10 с с известным
  разделителем и тем же окном / иначе честный отказ. Ставит точку отката
  (повторный Break = откат + rejected). Учит пару (≥2 букв, только буквы,
  не словарные). Раскладку не меняет при перевороте одиночной буквы.
- **Ctrl+Space (точное исправление):** два пути — если после слова ничего
  не нажималось (счётчик == 0, есть снимок слова) → конвертация буфера как
  manual (проходит лок и rejected); иначе — выделение слова слева
  (Ctrl+Shift+Left, только SendInput) и конвертация как выделенного текста
  с одним ретраем «2 слова влево». Неудача → плашка «Раскладка уже верная».
- Оба пути работают при Paused ≠ блокировка: Ctrl+Space при паузе отказывает
  («в ворота» упирается), force-flip — работает.

## 10. Раскладка и Shift

- Тап левого Shift (без других клавиш, keyup в пределах 700 мс; клик или
  чужая клавиша между down/up отменяет) → русский; правого → английский.
  Тап фиксируется на keyup.
- Двойной Shift (второе нажатие в пределах 400 мс) **отключён**, пока
  тап-переключение висит на Shift'ах (два тапа = два переключения, а не
  тап + двойной-шифт = «шифт не отрабатывает»).
- После ручного переключения — gap-компенсация 800 мс (§6.5) и проверка
  применения раскладки через 400 мс с fallback'ом (см. §16).

## 11. Словари, морфология, скоринг

- `WordDict`: ручные частотные списки (~400 слов, вкл. живой лексикон) +
  частотники OpenSubtitles (RU 35k / EN 20k, слова ≥ 3 букв) в сборке.
- `PossibleWord(word, lang)`: слово чисто из букв и **каждая** пара соседних
  букв присутствует в наборе биграмм языка (набор выводится из корпуса
  WordData + ручные таблицы). Покрывает формы вне словаря («нажимал»).
  Отсекает мусор («каая» — «аа», «воо» — «оо»).
- ГЕЙТ «набранное — возможное слово своего языка» СУЩЕСТВОВАТЬ НЕ МОЖЕТ:
  wrong-layout набор («руддщ», "ghbdtn") тоже состоит из валидных русских
  пар — им убивается ядро (ghbdtn→привет). Единственный дискриминатор
  правильного текста — валидность ЧУЖОГО прочтения (§5.11).

### 11.1. Скоринг (переносится из LanguageTables.cs дословно)

```
score(w, lang) = (Σ log10(биграмма) + 0.6 · Σ log10(буква)) / 1.6 / len
  частота незнакомой биграммы = 0.01 (BiFloor), буквы = 0.02 (UniFloor)
  результат капится снизу на −3
RowBoost: +0.6, если слово (≥4 букв) совпадает с началом/целым
  клавиатурным рядом языка (так «руддщ»→"hello" и "qwerty"→«йцукен»
  проходят скоринг)
ShouldConvert: margin = 0.22/max(0.3, sens); best+RowBoost < cur+margin → no;
  best < HardFloor (−1.35) → no; в цели обязательна гласная; пол цели
  EN −0.05 / RU −0.55.
Таблицы: 33 униграммы и ~100 биграмм на язык (литералы LanguageTables.cs) —
  при порте перенести ДОСЛОВНО.
```

## 12. Самообучение

- **accepted** (конвертировать всегда; пробивает скоринг, словарные ворота
  и кулдаун — но цель всё равно только из букв): слово, чья замена не была
  отменена в течение 15 с (честный таймер), ≥ 3 букв.
- **rejected** (никогда не конвертировать): отменённые (Break/backspace)
  слова и force-flip-откаты.
- Force-flip учит пары ≥ 2 букв, только буквенные, не словарные
  (словарные буквы-«предлоги» и мусор со знаками не заучиваются).
- Пары, заученные ручными действиями (force-flip, выделение), принимаются
  немедленно; авто-замены — через 15 с. Откат через Break удаляет из
  accepted и кладёт в rejected.
- Лимиты: каждый список ≤ 1000 слов (при переполнении обучение молча
  останавливается); в настройках есть команда «Забыть изученные слова».
- Файлы: `accepted.txt`, `learned.txt` (слово в строке, lower).

## 13. Force-flip и Enter-флип одиночной буквы

- Break при нечего-отменять: переворот последнего слова — буфер (живое
  слово) / последнее слово ≤10 с с известным разделителем и тем же окном /
  иначе честный отказ. Ставит точку отката (повторный Break = откат +
  rejected). Учит пару (≥2 букв, только буквы, не словарные). Раскладку не
  меняет при перевороте одиночной буквы.
- На Enter одиночная буква тоже переворачивается ('f'+Enter → «а» + досыл
  Enter) — иначе 'f' в начале сообщения уходит неперевёрнутым.

## 14. Исключения, пауза, песочница

- Исключения: **точное имя файла процесса в нижнем регистре, с
  расширением** («cmd.exe»); список через запятую или точку с запятой.
  Внутри исключений молчат вся авто-логика и Ctrl+Space/force-flip;
  работают Shift+Break, Break-откат уже сделанной замены, тапы Shift и
  песочница в настройках.
- Пауза (трей): всё авто молчит, ручные хоткеи работают; снятие паузы —
  «с чистого листа». Есть глобальный хоткей паузы (по умолчанию не
  назначен), сохраняет состояние и сбрасывает лок при снятии.
- Песочница: в собственном окне настроек авто-логика выключена везде,
  кроме тестового поля «Попробуйте»; ручные хоткеи работают.

## 15. Отладка

- **F8** — метка в журнал: proc/hwnd/hkl/буфер/последнее слово/undo/лок/
  suppress/последняя конвертация. Юзер жмёт при глюке → разбор по метке.
- Лог: ротация 2 МБ; полная трассировка решений по пробелу
  (`space: flip+resend/pass bufWas=N echoInWindow=y/n`), single-letter,
  force-flip, undo, learning, hook REVIVED.
- Watchdog: heartbeat раз в 100 с; `hook REVIVED after death` при оживлении.

| Windows | macOS |

Разрешения macOS: Accessibility (инжекция+AX), Input Monitoring (чтение
событий). Без них — тихая деградация: события не читаются/не инжектируются.

(см. System Settings) — семантика «сменил окно» сохраняется. Фонетические
русские раскладки НЕ поддерживаются спекой: маппинг по позиции клавиш
(йцукен) — проверить у юзера, какая раскладка. `TISSelectInputSource`
асинхронен — после смены проверять применение и предусматривать fallback.

## 17. Грабли, на которые уже наступали (НЕ повторять)

1. **Watchdog/таймеры из потоков без цикла сообщений** — хуки, поставленные
   из threadpool-потока, молча не получают колбэки. Все таймеры — только
   на UI-потоке; каждый таймер обязан быть запущен (`t.Start()`!).
2. **Не рвать слова по клавишам-двойникам** (б/ю/ж/э/х/ъ/ё) — «вообще»
   разваливалось на три куска.
3. **Не добавлять guard «набранное — возможное слово своего языка»** —
   wrong-layout набор тоже «возможен»; им убивается ghbdtn→привет.
4. **Модификаторы в комбо держать зажатыми** до основной клавиши
   (Ctrl↓ Ctrl↑ C↓ = голая «c», копирования нет).
5. **Досылать проглоченный разделитель символом исходной раскладки**
   (',' не превращается в «б»).
6. **Точку отката ставить только при реально доставленной инжекции** —
   иначе Break стирает живой текст.
7. **Принятие в самообучение — только после окна отмены** (15 с), иначе
   один случайный флип закрепляется навсегда; коротышей и словарные слова
   авто-заучиванием не трогать. Пары от ручных действий принимаются сразу.
8. **Эхо-фильтр пробела — одноразовый**, иначе съедаются легитимные пробелы.
9. **Кулдаун 5 с после ручной правки** — иначе пинг-понг переворотов.
10. **Хвостовой знак-двойник в перевороте слова — знаком**, а не буквой
    («ghbdtn,» → «привет,», а не «приветб»).
11. **Undo учитывает фактический разделитель, окно и фокус ввода.**
12. **Suppress-окно: буквы буферизуются, пробел делит буфер.**
13. **F8-метка/трассировка пробелов логируются всегда** — без них разбор
    жалобы невозможен.
14. **Двойной Shift отключён при тап-переключении на Shift'ах** — иначе
    второй тап «съедается» («правый шифт не отрабатывает»).
15. **Одиночные буквы**: только wordness-флип (§7); никакой контекстной
    эвристики по прошлой конвертации — она переворачивала правильное «а».
16. **VK-коды знаковых клавиш сверять с раскладкой** (инверсия 0xDC/0xDD
    рвала слова с «ъ»).

## 19. Критерии приёмки (проверить на порте)

1. `ghbdtn` + пробел → «привет» + один пробел.
2. `ghbdtn,` + пробел → «привет,».
3. `djj,ot` + пробел → «вообще».
4. `f` + пробел после русского предложения (фактическая раскладка EN) → «а».
5. `f` + Enter (отправка в чат) → «а» + отправка.
6. Break после замены → откат; Break без замены → переворот последнего
   слова; повторный Break → откат переворота.
7. «шифт», «сверху», «нажимал», «дубках» в правильной раскладке — никогда
   не переворачиваются.
8. Двойной пробел не появляется после конвертаций; намеренный двойной
   пробел (пауза > 600 мс) сохраняется.
9. Тап Shift → буквы, набранные в течение 800 мс после тапа, доставляются
   в новой раскладке (gap-компенсация).
10. `dct` + пробел в EN → «все» (2-буквенные формы словарные).
11. Backspace сразу после замены → мгновенная отмена + слово в rejected.
12. Backspace позже 15 с после замены → ничего не ломает (просто забой).
13. Break позже 15 с → плашка «Слишком поздно», текст не тронут.
14. Слова с «ъ» («съел») не рвутся.
15. Force-flip сохраняет разделитель («привет», Break → «здорово» + пробел
    на месте).
16. В исключённом приложении: авто молчит, Shift+Break работает.
17. Буфер обмена восстанавливается после Shift+Break.
18. learned/accepted переживают перезапуск приложения.
19. Замена + немедленный набор следующего слова (suppress) → второе слово
    конвертируется, склейки нет.
20. Второй запуск приложения открывает настройки (single instance).
21. «GHBDTN» (Caps) → «ПРИВЕТ».
